# Новые версии подсветок синтаксиса QSP для ведения документации

## Подсветка синтаксиса для Docusaurus

Благодаря нейросетям удалось быстро и просто обновить подсветку синтаксиса для Docusaurus. Теперь она умеет много больше, чем умела раньше. Например, вот это:

```qsp
! сломанный комментарий:
! {
	"
}
*pl 'Если строка закомментирована - комментарий работает правильно'
! закрываем кавычку коммента "
! закрываем скобку коммента }
*pl 'Если строка закомментирована - комментарий сломан'
```

Файл подсветки доступен прямо в текущем репозитории: [`qsp-syntax.js`](https://github.com/QSPFoundation/qspfoundation.github.io/blob/main/src/theme/qsp-syntax/prism-qsp.js). Так же вам понадобится обновлённый файл стилей [`qsp-syntax.css`](https://github.com/QSPFoundation/qspfoundation.github.io/blob/main/src/css/qsp-syntax.css).

Установка не изменилась с прошлого раза, а если у вас уже установлена подсветка синтаксиса QSP для Docusaurus, вам достаточно просто заменить вышеназванные файлы. Для тех же, кто будет ставить подсветку с нуля, вот инструкция:

### Установка в другой проект Docusaurus

1. В корне проекта на Docusaurus Classic создайте swizzled-файл регистрации Prism:

   ```bash
   npm run swizzle @docusaurus/theme-classic prism-include-languages
   ```

2. Скопируйте `prism-qsp.js` в `src/theme/qsp-syntax/` проекта, сохранив имя файла.

3. Внутри функции `prismIncludeLanguages` в `src/theme/prism-include-languages.ts` временно сделайте экземпляр Prism глобальным, загрузите компоненты и подключите грамматику до удаления глобальной ссылки:

   ```ts
   const prismGlobal = globalThis as typeof globalThis & {
     Prism?: typeof PrismObject;
   };
   prismGlobal.Prism = PrismObject;

   additionalLanguages.forEach((lang) => {
     require(`prismjs/components/prism-${lang}`);
   });
   require('./qsp-syntax/prism-qsp.js');
   delete prismGlobal.Prism;
   ```

   Если swizzled-файл уже устанавливает и удаляет `globalThis.Prism`, не дублируйте эти строки: вставьте `require` после загрузки компонентов и до очистки глобальной ссылки. Не переносите `require` в начало файла.

4. Скопируйте `qsp-syntax.css` в `src/css/`. Добавьте его к `theme.customCss` в `docusaurus.config.ts`, сохранив уже подключённые стили:

   ```ts
   theme: {
     customCss: [
       './src/css/custom.css',
       './src/css/qsp-syntax.css',
     ],
   },
   ```

5. Используйте язык `qsp` в ограждённых блоках Markdown и запустите сайт или сборку:

   ````md
   ```qsp
   msg "<<$name>>"
   ```
   ````

### Основные ограничения и отличия от PEG

- Подсветка не проверяет структуру выражений и операторов, число аргументов, допустимость команды в конкретном контексте или соответствие `end` открывающему его блоку. Например, `&` выделяется как оператор без определения, является ли он конкатенацией или разделителем операторов.
- Заголовок локации распознаётся только в форме `# имя`. PEG допускает отсутствие пробела после `#`, но здесь пробел обязателен, чтобы не путать заголовок с переменной вроде `#counter`.
- Квадратные скобки остаются обычной пунктуацией: содержимое подсвечивается общей грамматикой QSP, но отдельного токена-обёртки для кортежа нет. Это также не позволяет различать кортеж и индекс массива только по стилю.
- Вложенные блоки `{...}` подсвечиваются с ограничением глубины 20; неограниченную рекурсию PEG эта regex-грамматика не воспроизводит.
- Продолжение строки в форме ` _` перед переводом строки не имеет отдельного токена и может выглядеть как имя переменной.
- `@` и `@@` подсвечиваются одним типом `user-call`; различие между вызовом пользовательской функции и оператором-вызовом не проверяется.

## Подсветка QSP для Obsidian

Изначально созданная как побочный проект, теперь подсветка кода QSP для Obsidian стала самостоятельным и вполне полноценным плагином. Вы можете найти её всё по тому же адресу:

- **[qsp-syntax-obsidian](https://github.com/AleksVersus/qsp-syntax-obsidian)**

Поддерживает всё то же, что и подсветка для Docusaurus, расхождения только в архитектуре скриптов из-за особенностей работы с плагинами у Докузауруса и Обсидиана. Установка ещё проще:

- скачиваете архив из последнего [релиза](https://github.com/AleksVersus/qsp-syntax-obsidian/releases);
- извлекаете из него папку `qsp-syntax-obsidian` в папку `.obsidian/plugins` вашего хранилища;
- перезагружаете Obsidian;
- идёте в `Натройки → Сторонние плагины → включаете плагин подсветки синтаксиса QSP`.

Можно пользоваться. Как и с подсветкой для докузауруса, есть некоторые ограничения и особенности работы.
